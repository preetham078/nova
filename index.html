Nova is an early Android prototype exploring a more personal way to talk with AI. Speak naturally, keep control of your setup, and choose whether to connect an AI service.

Phase 1 · Android prototype

Privacy-conscious by design

Your API key is encrypted locally. Conversation context is kept in memory.

This page introduces Nova; the prototype is a native Android app and does not run in a web browser. See the project README to build and run it.
